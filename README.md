# Proffy — Plataforma Educacional

Plataforma educacional criada para conectar **alunos e professores**, facilitando a busca por aulas e o contato entre usuários.

> Projeto originalmente desenvolvido durante a **Next Level Week (NLW), da Rocketseat**, como parte da minha jornada de aprendizado em desenvolvimento web.

---

## Sobre o projeto

O Proffy foi um dos projetos que fizeram parte da minha formação inicial como desenvolvedor.

A primeira versão foi construída utilizando **HTML, CSS e JavaScript**, com foco em aprender os fundamentos do desenvolvimento web, estruturação de páginas, estilização, interações e organização de uma aplicação.

O projeto será posteriormente retomado e evoluído como um projeto pessoal, aplicando conhecimentos adquiridos ao longo da minha trajetória em desenvolvimento Full Stack.

A ideia é transformar o Proffy em um laboratório de evolução técnica, mantendo sua origem registrada e documentando as decisões tomadas durante sua modernização.

---

## 🎯 Objetivo

Criar uma plataforma que facilite a conexão entre **alunos que procuram aulas** e **professores que desejam disponibilizar seus conhecimentos**.

A aplicação permite explorar professores e suas áreas de atuação, além de possibilitar o contato e o agendamento de aulas.

---

## 📈 Evolução do projeto

O Proffy representa uma parte importante da minha evolução como desenvolvedor.

### Etapa 01 — Projeto original

**NLW Rocketseat**

Tecnologias:

`HTML` `CSS` `JavaScript`

Primeiro contato com a construção de uma plataforma web completa.

### Etapa 02 — Retomada

Revisão do projeto original e análise da estrutura existente.

Objetivos:

* compreender novamente o código;
* identificar pontos de melhoria;
* revisar decisões da implementação original;
* estabelecer uma nova arquitetura.

### Etapa 03 — Modernização

Aplicação dos conhecimentos adquiridos posteriormente em desenvolvimento Full Stack.

Planejamento:

`React` `TypeScript` `Node.js` `API REST` `Banco de Dados`

### Etapa 04 — Engenharia

Evolução gradual da aplicação com foco em:

* arquitetura;
* validação;
* autenticação;
* testes;
* segurança;
* documentação;
* qualidade de código.

### Etapa 05 — Produção

Preparação da aplicação para execução em ambiente de produção, incluindo:

* Docker;
* variáveis de ambiente;
* deploy;
* monitoramento;
* documentação de execução.

> As etapas futuras serão implementadas gradualmente e documentadas conforme o projeto evoluir.

## Como executar

### Clone o repositório

```bash
git clone https://github.com/Johnatan-boot/Proffy_Plataforma_Educacional.git
```

### Acesse o projeto

```bash
cd Proffy_Plataforma_Educacional
```

### Execute

Como a versão atual utiliza HTML, CSS e JavaScript, basta abrir o projeto em um servidor local.

Uma opção é utilizar a extensão **Live Server** no VS Code.
